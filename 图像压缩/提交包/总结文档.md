# 图像压缩实习报告 · 结果总结

> 本文件为评测结果汇总，供撰写正式实习报告时直接引用。

## 1. 任务与数据

- 数据集：Kodak Lossless True Color Image Suite，24 张 24bit 真彩色 RGB 图（768×512 / 512×768）。
- 任务：图像压缩算法设计与实现，对比压缩前后质量与压缩效率。
- 评价指标：压缩率（bpp）、PSNR、SSIM、压缩/解压缩时间。
- 基准口径：压缩率以原始像素量 `H×W×3` 字节为分母；bpp = 压缩总比特 / 像素数。

## 2. 实现方案

### 2.1 自研 JPEG 风格 DCT 编码器（对比基线）

- 颜色空间：RGB → YCbCr（4:4:4，无色度下采样）。
- 变换：8×8 分块 DCT（正交归一）。
- 量化：JPEG 标准量化表按质量因子 Q 缩放（Q∈[1,100]）。
- 熵编码：Zigzag 扫描 + DC 差分 + AC 游程(RLE) + 规范哈夫曼编码。

### 2.2 AVIF（AV1 帧内编码）

- AVIF 基于 AV1 视频编码器的帧内编码模式，采用更先进的块划分、
  多种变换核与更精细的环路滤波，率失真性能显著优于 JPEG。
- 通过 libavif（pillow-avif-plugin）调用，质量因子 Q 控制量化。

## 4. 率失真对比（关键结论）

- PSNR 相当（AVIF 26.4dB vs 自研JPEG 26.9dB）时，AVIF bpp=0.115 vs JPEG bpp=0.311，节省约 63% 码率。
- PSNR 相当（AVIF 33.1dB vs 自研JPEG 32.7dB）时，AVIF bpp=0.622 vs JPEG bpp=1.028，节省约 40% 码率。

- RD 曲线见 `results/rd_psnr.png` 与 `results/rd_ssim.png`；
  压缩前后对比图见 `results/compare_*.png`。

## 5. 结论（可直接引用的话术）

1. 自研 DCT 编码器完整实现了「变换 + 量化 + 熵编码」的有损压缩链路，
   随质量因子 Q 增大，bpp 与 PSNR/SSIM 单调上升，符合率失真基本规律。
2. AVIF（AV1 帧内编码）在相同 PSNR 下码率显著低于传统 DCT 编码，
   体现了先进编码标准（更精细的块划分、多种变换与环路滤波）在率失真性能上的优势。
3. AVIF 的编解码由底层 C 库（libavif）完成，速度快于纯 Python 实现的自研 DCT；
   这一速度差异主要来自实现语言，而非压缩算法本身的复杂度，报告撰写时应如实说明。
