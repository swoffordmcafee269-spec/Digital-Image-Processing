# 部署与运行说明

## 数据与环境

- 使用本机 Python 和 NVIDIA CUDA。当前确认环境是 PyTorch 2.11.0+cu128、RTX 5060 Laptop 8GB。
- `configs/canon.json` 指定外部只读数据目录和项目内部产物目录。
- 全部命令在本项目目录运行。所有输出均受路径检查保护，不能写入原始数据集。
- 预留约 60GB：GT 解码缓存约 25GB，两种方法的 PNG、模型与日志占用其余空间。
- 数据、场景划分、色彩标定、训练和推理配置必须配套。程序会检查权重与数据清单指纹。

本机已具备所需环境，不必在训练过程中重装依赖。迁移时可新建虚拟环境并安装；精确版本见 `requirements-lock.txt`，CUDA 版 PyTorch 需要对应官方索引：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128
python -m pip install -r requirements-lock.txt
```

安装可用性取决于目标机器的 Python、驱动及平台；本次实测版本记录于 `artifacts/environment.json`。LPIPS 第一次使用可能下载公开 AlexNet 权重，离线迁移需保留其 torch hub 缓存；该权重仅用于通用感知评价，不是预训练 RAW 增强模型。

## 准备与测试

```powershell
python -m unittest discover -s tests -v
python -m canon_enhance.prepare
```

准备阶段读取全部 1000 对文件、在项目内创建 GT 缓存、生成可复现场景分组、划分和训练集颜色标定。它不修改原 RAW/JPEG。随机种子固定，GPU 内核允许性能优化，因此不承诺跨设备逐位相同。

`artifacts/data/contact_groups.jpg` 可辅助检查分组；划分详情在 `manifest.json`。ORB 分组是启发式防泄漏措施，不是官方场景标注。

## 训练与续训

```powershell
python -m canon_enhance.train --name main --chroma-weight 0 --stop-after 18000
python -m canon_enhance.train --name chroma0 --resume artifacts/checkpoints/main/last.pt --chroma-weight 0 --ema-decay 0.999 --stop-after 22000
python -m canon_enhance.train --name chroma005 --resume artifacts/checkpoints/main/last.pt --chroma-weight 0.05 --ema-decay 0.999 --stop-after 22000
python -m canon_enhance.train --name adaptive --resume artifacts/checkpoints/main/last.pt --adaptive-proxy --chroma-weight 0.05 --ema-decay 0.999 --learning-rate 0.0001 --stop-after 24000
```

两条色度消融从同一共享训练权重和优化器状态开始，使用相同的随机种子及数据顺序，比较相同验证集。实际实验如有更改，必须以 logs 中的配置和完成状态为准。

默认每 2000 步验证一次，每 500 步保存 last.pt。达到步骤或墙钟时间上限后保存退出。`--resume` 可恢复模型、优化器和 AMP scaler；DataLoader 重建，不承诺位级续训轨迹完全相同。

后续候选用 EMA 权重验证及保存 best；last.pt 保存实时权重、EMA 和优化器用于续训。adaptive 候选压缩 RAW 特征动态范围并学习抑制含噪颜色初值；结构变化时兼容层迁移，优化器重置。流水线按固定验证集选模，若较高目标未达到，再追加最多 4000 步的小权重 LPIPS 实验，最终仍使用同一选模规则。

检查进度：

```powershell
python -m canon_enhance.status
```

## 独立推理

```powershell
python -m canon_enhance.inference D:/BaiduNetdiskDownload/BIED/Canon_0.0001/0.0001/10.raw --checkpoint artifacts/checkpoints/selected.pt --output artifacts/previews/10.png
```

此命令仅需要 RAW 和权重，不需要 GT。权重内包含模型结构、黑电平、尺度和训练集颜色映射。默认整图；显存不足时使用有重叠上下文的分块。分块推理复用完整图像的上下文，并保持网络采样相位。

只做整目录增强、不提供 GT 的命令如下。它只加载一次模型；默认不覆盖已有结果，同模型同输入可用 `--resume` 继续。

```powershell
python -m canon_enhance.batch D:/BaiduNetdiskDownload/BIED/Canon_0.0001/0.0001 --checkpoint artifacts/checkpoints/selected.pt --output-dir artifacts/prediction_only
```

## 全量输出与评价

```powershell
python -m canon_enhance.evaluate --checkpoint artifacts/checkpoints/selected.pt --name final
python -m canon_enhance.evaluate --baseline --name baseline
python -m canon_enhance.verify --name final
python -m canon_enhance.verify --name baseline
python -m canon_enhance.acceptance
python -m canon_enhance.report
python -m canon_enhance.prepare --verify-source
```

输出到 `artifacts/results/<name>/images`。逐图指标为 `metrics.csv`，汇总为 `summary.json`。中断后使用相同命令追加 `--resume`；如模型、数据或图像名单变化，必须使用新实验名。

最终图片写成 PNG 后重新读取再评分。LPIPS 使用本机已缓存的 AlexNet 及 lpips v0.1 权重；若迁移到离线机器，需一同准备其公开权重文件。

已有 PNG 也可单独评价，不加载增强模型、不重新出图：

```powershell
python -m canon_enhance.score artifacts/results/final/images --gt-dir D:/BaiduNetdiskDownload/BIED/Canon_gt/gt --output-dir artifacts/rescore
```

`score` 对所给文件夹的全部 PNG 按同名 JPEG 配对，输出该文件夹的整体统计；训练/验证/测试分组统计以完整流水线的 `summary.json` 为准。

`acceptance` 使用实际冻结权重，检查 RAW-only 单张推理与提交图片的一致性、512 packed 像素分块/192 halo 与整图的一致性，并抽取 10、100、798 三张保存图片复算指标。CUDA AMP 在不同张量形状下可能有 1 个 uint8 灰度级的数值差异，结果保存在 `artifacts/results/final/acceptance.json`。本次该检查已通过。

## 交付与边界

提交源码、configs、requirements/environment、部署说明、实习报告、选定模型、1000 张结果与指标。`artifacts/cache` 是可重建缓存，无需提交。不要把老师的原始数据打包进项目。

全量均值包含训练图，必须同时保留独立测试集均值。禁止根据每张测试图 GT 单独调曝光、白平衡或挑选模型。报告中的所有性能数字均从实际产物生成。
