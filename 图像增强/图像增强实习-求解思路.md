# 图像增强实习作业 · 题目分析与求解思路

> 课程：《数字图像处理》课间实习（武汉大学，2026-09-30 布置，第 8 周提交）

## 一、题目解析

### 1.1 任务定义
基于 **SIED 数据集**（ICCV 2025 论文 *Learning to See in the Extremely Dark* 配套数据集），
完成**从极暗 RAW 图像到正常曝光 sRGB 图像**的增强任务。

- 课程数据入口：`github.com/wenwang123/Digital-Image-Processing`
- 官方论文/代码：`github.com/JianghaiSCU/SIED`（扩散模型方案）
- 两个子集：`Canon_0.0001`（0.0001–0.001 lux）、`Sony_0.001`（0.001–0.01 lux），各含 **1000 对**"低光照 RAW ↔ 高质量 sRGB GT"

### 1.2 题目的三个关键点
1. **输入是 RAW 而非普通图片**——这是与一般"图像增强"作业最大的区别。0.0001 lux 的 RAW
   肉眼看几乎全黑（PPT 样例即如此），且信噪比极低。
2. **任务本质是三合一**：低光增强 + 强去噪 + 曝光/色彩恢复。直接拉亮度会把噪声放大到不可用，
   这决定了主流解法是 RAW 域深度学习（SID 范式）。
3. **评分硬指标**：PSNR、SSIM、LPIPS，对 **1000 张全量**计算；交付可复现源码 + 部署文档 +
   报告（指标结果 + 前后可视化对比图）。

## 二、三条求解路线（分层拿分策略）

### 路线 A：传统方法基线（1 天，保底分，必做）
- 流程：rawpy 读 RAW → 简单线性化 → **Gamma 校正 / 直方图拉伸 / CLAHE / Retinex(MSR)** 逐个试
- 作用：报告中作为对比基线，衬托深度方法的优势；代码量小、必定跑通
- 预期：PSNR 很低（约 12–18 dB），噪声明显——这正是想要的效果

### 路线 B：轻量 UNet 监督学习（推荐主线，1–2 周）
1. **RAW 预处理**：黑电平扣除 → 按白电平归一化 → RGGB 四通道打包（H/2 × W/2 × 4）
2. **数据划分与增强**：约 900 张训练 / 100 张验证；随机裁剪 256×256 patch + 随机翻转/旋转
3. **网络**：4–5 级下采样的 UNet，输入 4ch RAW → 输出 3ch（或 4ch 再做 demosaic）
4. **损失**：L1 + SSIM（可选再加 VGG 感知损失）
5. **训练技巧**：AMP 混合精度、Adam lr=1e-4、cosine 衰减、batch 8–16、几十个 epoch 即可收敛
6. **后处理 ISP**：白平衡 → 色彩校正矩阵 CCM → Gamma 2.2 → 裁剪到 [0,1]
- 预期：Sony 子集 PSNR 可达 25–30 dB 量级，视觉效果接近 GT

### 路线 C：扩散模型冲高分（选做）
- 直接跑通官方 SIED 仓库的推理（或按论文复现简化版），在报告中作为"先进方法对比"
- 显存不够时可改用更轻的 SOTA（如 Retinexformer 类方法）做对比

## 三、评估方案
- **PSNR / SSIM**：`scikit-image`（sRGB 域、与 GT 逐对计算后取 1000 张均值）
- **LPIPS**：`lpips` 库（PyTorch 实现，AlexNet/VGG backbone 均可）
- 输出：逐张指标 CSV + 均值汇总表 + 三联对比图（输入 | 输出 | GT）

## 四、编程工具推荐：Python（明确首选）

| 用途 | 推荐库 | 说明 |
|---|---|---|
| RAW 读取 | `rawpy` | LibRaw 封装，直接读 .ARW/.CR2，含黑电平/白平衡元数据 |
| 数组运算 | `numpy` | 四通道打包、归一化 |
| 网络与训练 | `torch` + `torchvision` | GPU 训练、AMP |
| 传统增强方法 | `opencv-python`、`scikit-image` | CLAHE、Retinex 等 |
| 指标 | `scikit-image`、`lpips` | PSNR/SSIM/LPIPS 一站式 |
| 可视化 | `matplotlib` | 对比图、曲线 |
| 辅助 | `tqdm`、`pyyaml`、`pandas` | 进度条、配置、指标表 |

- **环境管理**：venv 或 conda + `requirements.txt`；代码用 git 管理（课程实习第一部分就是 GitHub）
- **为什么不用 MATLAB**：LPIPS 无官方实现、RAW 读取支持差、深度学习训练生态弱
- **为什么不用 C/C++**：本题核心是算法实验而非性能工程，Python 生态碾压

## 五、硬件与环境建议
- 最优：NVIDIA GPU（≥6–8 GB 显存），patch 训练足够
- 无 GPU 的替代：① Google Colab / Kaggle 免费 T4；② 降低分辨率/patch 大小训练；③ 只做路线 A + C 的推理
- 注意：1000 对 RAW 数据体积可能达数十 GB，预留磁盘空间，训练时按需读取
