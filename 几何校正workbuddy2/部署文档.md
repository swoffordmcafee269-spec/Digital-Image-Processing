# 部署文档 —— 数字图像处理实习二：文档图像几何校正

## 1. 环境要求

- Windows 10/11（其他平台理论可用）
- Python 3.10+（本项目使用 3.13）
- NVIDIA GPU（可选，UVDoc 推理建议；无 GPU 自动回退 CPU）
- 磁盘空间：约 5 GB（含 PyTorch GPU 版）

## 2. 环境安装

```bash
# 1) 创建虚拟环境（项目目录下）
python -m venv venv

# 2) 激活（PowerShell / bash）
venv\Scripts\activate        # Windows
source venv/bin/activate     # Linux/macOS

# 3) 安装 PyTorch（GPU 版，CUDA 12.8；无 GPU 用 CPU 版）
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
# CPU 版: pip install torch torchvision

# 4) 安装其余依赖
pip install opencv-python numpy matplotlib tqdm rapidocr-onnxruntime
```

## 3. 数据准备

解压 `GeoCorrection.zip` 到：

```
GeoCorrection/_extract/GeoCorrection/
├── images/   # 200 张畸变文档图 (.jpg)
└── mask/     # 200 张同名二值掩码 (.png, 文档区域=255)
```

## 4. UVDoc 模型

预训练权重随仓库分发，位于 `uvdoc/UVDoc/model/best_model.pkl`。
若丢失，从 https://github.com/tanguymagne/UVDoc 重新获取（或国内镜像 `https://gh-proxy.com/https://github.com/tanguymagne/UVDoc/archive/refs/heads/main.zip`）。

## 5. 运行步骤（按顺序）

```bash
# ① 方案A: 传统透视校正 baseline（~1 分钟）
python baseline/01_baseline.py

# ② 方案C: UVDoc 神经网络 dewarping，GPU 推理（~2 分钟）
python uvdoc/02_uvdoc_infer.py

# ③ 可视化对比图：原图 | baseline | UVDoc（~1 分钟）
python eval/03_visual_compare.py

# ④ 文字行规整度量化（~1 分钟）
python eval/04_line_regularity.py

# ⑤ OCR 对比评估（rapidocr 本地推理，~60-90 分钟）
python eval/05_ocr_eval.py

# ⑥ 汇总统计表
python eval/06_summary_stats.py
```

## 6. 输出说明

| 路径 | 内容 |
|---|---|
| `results/baseline/` | 方案A 校正结果（200 张） |
| `results/uvdoc/` | 方案C（UVDoc）校正结果（200 张） |
| `results/compare/` | 每张三联对比图；`_grid_sample.jpg` 为抽样总览 |
| `eval/metric_line_regularity.csv` | 文字行规整度（curvature 越小越好，line_var 越大越好） |
| `eval/metric_ocr.csv` | OCR 字符数/行数/置信度（原图 vs baseline vs uvdoc） |
| `eval/summary_stats.csv` | 汇总统计表 |
| `eval/*_log.csv` | 各步骤运行日志 |

## 7. 常见问题

- **cv2.imread 返回 None**：路径含中文/空格。本项目已在 `common/imgio.py` 用 `np.fromfile + imdecode` 处理。
- **torch.cuda.is_available() 为 False**：RTX 50 系显卡必须用 cu128 wheel（torch≥2.7）。
- **OCR 速度慢**：`05_ocr_eval.py` 中 `MAX_SIDE = 2000` 控制输入尺寸，可调小加速。
